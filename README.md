# Portfolio — Mathias ALY BERIL

Portfolio personnel de Mathias ALY BERIL, étudiant ingénieur en informatique en 5ᵉ année à l'ESIROI
(Université de La Réunion) : projets, compétences et parcours en développement logiciel,
cybersécurité, data/IA, systèmes & réseaux et embarqué.

Site statique HTML / CSS / JavaScript, sans framework ni build, avec un thème sombre
« cyber » animé. Déployé avec GitHub Pages :
https://silverwolf974.github.io/portfolio-mathias/

Pour le lancer en local, il suffit d'ouvrir `index.html` dans un navigateur.

Le bouton **FR / EN** ouvre la même page dans l'autre langue. L'accueil et les neuf
fiches projet sont disponibles en anglais dans `en/`. Les liens de navigation restent
dans la langue choisie ; les deux CV restent accessibles depuis chaque accueil.
Le téléchargement principal et le QR code suivent la langue de la page.

Pour mettre à jour les traductions, modifier les pages françaises et les textes
correspondants dans `locales/en.json`, puis exécuter `python scripts/build-locales.py`.
Ce script génère les pages anglaises et les boutons de langue ; il signale tout texte
sans traduction. Les fichiers générés sont inclus dans le site : aucune compilation
n'est nécessaire pour consulter ou héberger le portfolio.
