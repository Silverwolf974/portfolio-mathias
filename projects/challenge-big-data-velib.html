Challenge Big Data — prédiction Vélib'

Cadrage d'un pipeline Big Data (Spark) pour analyser et prédire l'usage des vélos en libre-service Vélib' à partir de données ouvertes.

TypeChallenge — projet de groupe
ÉquipeBinôme
StatutPrototype / cadrage
DomaineBig Data / ML

Contexte

Projet de challenge autour de l'analyse et de la prédiction des données Vélib' (vélos en libre-service) croisées avec des données météorologiques, sur une architecture Big Data avec Apache Spark. Le projet est resté au stade du cadrage et de la structuration : il est présenté ici en toute transparence comme un prototype, pas comme un projet abouti.

Objectifs visés

  • Ingestion de données depuis des API publiques (Vélib', météo).
  • Traitement massif avec Spark (ETL).
  • Modèles de machine learning : prédiction de la demande, clustering de stations, analyse de tendances.
  • Visualisation des résultats.

Ce que ce projet démontre

Capacité à cadrer un pipeline Big Data de bout en bout (ingestion, ETL Spark, ML, visualisation), à structurer un dépôt de projet data et à documenter une architecture cible.

Technologies

  • Python
  • Apache Spark
  • HDFS
  • API Vélib'
  • OpenWeatherMap
  • Jupyter
Note : Projet volontairement présenté comme un cadrage : les notebooks et résultats n'ont pas été produits. L'honnêteté sur l'état d'avancement fait partie de la démarche.
