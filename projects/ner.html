Repérer les noms dans les textes

Évaluation d’un modèle entraîné sur Wikipédia pour repérer les personnes, les entreprises et les produits dans des tweets.

FormationINSA Lyon
DomaineAnalyse de texte

Contexte et objectif

Vérifier si un outil fiable sur des articles rédigés reste pertinent sur des messages courts et informels.

Travaux réalisés

J’ai remis en marche le code de départ et vérifié la façon dont les réponses étaient notées. Un des tests donnait un score parfait même lorsque le système associait les mauvais noms. J’ai ensuite exécuté les expériences finales sur Google Colab.

Résultats

Pour les noms d’entreprises, le score de reconnaissance passe de 0,68 sur Wikipédia à 0,07 sur les tweets.

Ce que j’ai appris

J’ai appris à relire les exemples avant de conclure : certaines erreurs venaient du modèle, d’autres d’une ambiguïté dans les réponses attendues.
