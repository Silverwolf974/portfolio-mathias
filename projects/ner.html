Repérer les noms dans les textes

J’ai testé si une IA entraînée sur Wikipédia reconnaissait aussi les personnes, les entreprises et les produits dans des tweets.

Ma contribution

J’ai remis en marche le code de départ et vérifié la façon dont les réponses étaient notées. Un des tests donnait un score parfait même lorsque le système associait les mauvais noms. J’ai ensuite exécuté les expériences finales sur Google Colab.

Ce que j’ai appris

En passant de Wikipédia aux tweets, le modèle reconnaissait beaucoup moins bien les entreprises. J’ai appris à relire les exemples avant de conclure : certaines erreurs venaient du modèle, d’autres d’une ambiguïté dans les réponses attendues.

Outils utilisés

  • RoBERTa
  • Google Colab
