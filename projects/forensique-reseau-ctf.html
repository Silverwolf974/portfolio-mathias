Forensique réseau — CTF

Investigation d'une capture réseau dans le cadre d'un exercice de type CTF : identifier une exfiltration de données dissimulée dans du trafic DNS et automatiser le décodage des flags.

TypeExercice pratique — module cybersécurité
FormatCTF / analyse forensique
OutilsWireshark, Python, PowerShell
StatutFlags récupérés

Contexte

À partir d'une capture réseau (.pcapng), l'exercice consistait à retrouver des informations dissimulées dans le trafic. L'analyse s'appuyait aussi sur des rapports de menace réels (CERT-FR) pour ancrer la démarche dans un contexte professionnel.

Démarche d'investigation

  • Analyse exploratoire de la capture dans Wireshark : identification des protocoles, des conversations et des volumes anormaux.
  • Repérage d'un canal d'exfiltration DNS : des données encodées en hexadécimal dans les labels des requêtes vers un domaine contrôlé par l'attaquant.
  • Écriture d'un script Python avec dpkt parcourant la capture, extrayant les labels DNS, les décodant (hex → UTF-8) et exportant le tout en TSV horodaté.
  • Scripts PowerShell complémentaires pour le décodage d'autres flags et la reconstruction de fichiers.
  • Vérification et corrélation des résultats (fichiers reconstruits, flags validés).

Ce que ce projet démontre

Réflexes d'analyste : lire une capture réseau, reconnaître un canal d'exfiltration discret, puis automatiser l'extraction plutôt que de décoder à la main. C'est exactement le type d'investigation menée en SOC lors d'une suspicion d'incident.

Technologies

  • Wireshark
  • Python 3
  • dpkt
  • PowerShell
  • DNS
  • Rapports CERT-FR
Note : Exercice réalisé dans un cadre pédagogique, sur une capture fournie par l'enseignant. Les scripts peuvent être présentés sur demande.
