Transmission sécurisée de données via MQTT

Chiffrer des données environnementales de bout en bout (AES) et les relayer via un broker MQTT qui ne voit jamais le contenu en clair.

TypeSAE — projet académique (ESIROI)
ÉquipeBinôme
LangageJava 17
StatutTerminé, fonctionnel

Contexte

Simuler la transmission de données environnementales (température, humidité) d'un équipement vers un poste « entreprise » via un broker MQTT, en garantissant la confidentialité des données, y compris vis-à-vis du broker lui-même.

Objectifs

  • Comprendre le modèle publish/subscribe de MQTT.
  • Implémenter un chiffrement bout-en-bout AES.
  • Appliquer une dérivation de clé robuste (PBKDF2) à partir d'un secret partagé.
  • Structurer une application Java modulaire et isoler la configuration.

Architecture et fonctionnement

Trois machines virtuelles Ubuntu sur un même réseau local : émetteur (équipement), récepteur (entreprise) et broker Mosquitto. La clé AES est dérivée d'un identifiant partagé via PBKDF2 ; le topic MQTT est dérivé par SHA-256. L'émetteur chiffre un message JSON et le publie ; le récepteur, abonné au même topic, déchiffre et affiche. Le broker ne manipule que du chiffré. L'adresse du broker est externalisée dans un fichier de configuration.

Travaux réalisés

  • Mise en place d'un broker Mosquitto local et validation de la chaîne publish/subscribe.
  • Classes Java : CryptoUtils (dérivation + chiffrement), ClientPublisher, ClientSubscriber.
  • Chiffrement AES-CBC des messages JSON avant publication.
  • Topic dérivé du secret partagé (cloisonnement des échanges).
  • Externalisation de la configuration réseau.

Résultats

Chaîne complète fonctionnelle : message chiffré côté équipement, relayé sans être lisible par le broker, déchiffré et affiché côté entreprise. Objectif de confidentialité bout-en-bout atteint dans le périmètre du projet.

Ce que ce projet démontre

Cryptographie appliquée (AES, PBKDF2, SHA-256), maîtrise du protocole MQTT, développement Java structuré et administration Linux en réseau local.

Technologies

  • Java 17
  • Eclipse Paho MQTT
  • Mosquitto
  • AES-CBC
  • PBKDF2-HMAC-SHA256
  • SHA-256
  • Ubuntu Server
