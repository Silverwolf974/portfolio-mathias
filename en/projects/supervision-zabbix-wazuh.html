Network monitoring — Zabbix, Wazuh & pfSense

Deploy and monitor a small virtualised infrastructure end to end: metrics with Zabbix, incident detection with Wazuh (SIEM), all behind a pfSense firewall.

TypeCybersecurity lab project (4th year)
TeamTwo students
PeriodNovember 2025
Scope4 virtual machines

Context

The whole infrastructure is virtualised on a single physical machine, on an isolated internal network managed by a firewall. It brings together four systems: a pfSense firewall (router and gateway), an Ubuntu monitoring server, a Linux application server and a Windows server joined to an Active Directory domain.

Objectives

  • Set up centralised monitoring of the machines and services.
  • Collect both system metrics and security logs.
  • Detect a security incident and correlate it with the metrics.
  • Document a reusable architecture for a professional context.

Architecture set up

  • pfSense : firewall, router and gateway, which reports its information via SNMP and sends its logs over Syslog.
  • Ubuntu monitoring server hosting Zabbix (network and system metrics) and Wazuh in all-in-one mode (SIEM for correlation and log analysis).
  • Linux application server (Apache) and Windows server (Active Directory), each fitted with the Zabbix and Wazuh agents.

Monitoring carried out

  • Availability of the web service on the Linux server.
  • Integrity of a critical file on the Windows server.
  • Network performance and SNMP metrics of the pfSense firewall.

Security side

An SSH brute-force attack was simulated against the Linux server, then detected by the Wazuh SIEM from the authentication logs. Wazuh events (security) and Zabbix metrics (system) were then correlated to get a complete view of the incident.

Result

The whole chain works on a single host: service monitoring, metric collection, event correlation and real-time incident detection. The project proves that complete monitoring is feasible despite strong hardware constraints.

Difficulties and next steps

  • Fitting everything onto a single physical machine raised connectivity, compatibility and installation issues, solved over the course of the project.
  • Next steps: automate the deployment (Ansible or Docker Compose), add email alerts and cross dashboards with Grafana, and strengthen log rotation and centralisation.

Skills developed

  • Infrastructure monitoring with Zabbix.
  • SIEM and log analysis with Wazuh.
  • Configuring a pfSense firewall (SNMP, Syslog).
  • Windows Server / Active Directory and Linux administration.
  • Detecting and correlating security incidents.
