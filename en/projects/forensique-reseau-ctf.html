Network forensics — CTF

Investigating a packet capture in a CTF exercise: identifying data exfiltration hidden in DNS traffic and automating flag decoding.

TypePractical exercise — cybersecurity module
FormatCTF / forensic analysis
ToolsWireshark, Python, PowerShell
StatusFlags recovered

Context

Using a packet capture (.pcapng), the exercise involved recovering information hidden in network traffic. The investigation also drew on real threat reports from CERT-FR to connect the work to professional practice.

Investigation approach

  • Exploratory analysis of the capture in Wireshark : identifying protocols, conversations and unusual traffic volumes.
  • Identifying a channel forDNS exfiltration : hexadecimal-encoded data in query labels sent to an attacker-controlled domain.
  • Writing a script in Python using dpkt to iterate through the capture, extract DNS labels, decode them from hex to UTF-8 and export timestamped TSV data.
  • Additional PowerShell scripts to decode other flags and reconstruct files.
  • Verifying and correlating the results, including reconstructed files and validated flags.

Skills demonstrated

Analyst skills: reading a packet capture, recognising a covert exfiltration channel and then automating data extraction rather than decoding manually. This is the kind of investigation carried out in a SOC when an incident is suspected.

Technologies

  • Wireshark
  • Python 3
  • dpkt
  • PowerShell
  • DNS
  • CERT-FR reports
Note: An educational exercise using a capture supplied by the instructor. Scripts can be presented on request.
