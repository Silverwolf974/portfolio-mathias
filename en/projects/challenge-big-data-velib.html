Big Data Challenge — Vélib’ demand prediction

Scoping a Spark-based Big Data pipeline to analyse and predict Vélib’ bike-sharing usage from open data.

TypeChallenge — group project
TeamTwo students
StatusPrototype / scoping
FieldBig Data / ML

Context

A challenge project to analyse and predict Vélib’ bike-sharing usage by combining trip-related data with weather data on an Apache Spark architecture. The work remained at the scoping and project-structuring stage, so it is presented here as a prototype rather than a completed implementation.

Planned objectives

  • Ingest data from public APIs (Vélib’ and weather).
  • Process large datasets with Spark (ETL).
  • Apply machine learning to demand prediction, station clustering and trend analysis.
  • Visualise the results.

Skills demonstrated

Scoping an end-to-end Big Data pipeline (ingestion, Spark ETL, machine learning and visualisation), organising a data project repository and documenting a target architecture.

Technologies

  • Python
  • Apache Spark
  • HDFS
  • Vélib’ API
  • OpenWeatherMap
  • Jupyter
Note: This project is presented as a scoping exercise: notebooks and results were not produced. Its current stage is stated explicitly.
