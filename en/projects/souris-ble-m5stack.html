Motion-controlled Bluetooth mouse on M5Stack Core2

Turning an M5Stack Core2 (ESP32) into a tilt-controlled Bluetooth HID mouse with touchscreen click zones and onboard audio feedback.

TypeAcademic lab (2025)
TeamTwo students
HardwareM5Stack Core2 (ESP32)
StatusCompleted and working

Context

Designing an M5Stack Core2 interface that works as a Bluetooth HID mouse, controlled through buttons, the touchscreen and the inertial measurement unit (IMU).

Work completed

  • Compilation toolchain using arduino-cli and command-line flashing.
  • BLE HID validation: the host recognises the board as a mouse.
  • IMU pitch/roll readings control cursor movement; touchscreen zones handle clicks; the centre button enables scrolling.
  • Audio integration: WAV files converted into C headers stored in flash memory (PROGMEM).
  • Modular code: BleMouseModule, ImuDirectionModule, ButtonUI.

Challenges overcome

  • BLE Mouse library missing from the Arduino index: manually installing and patching a fork.
  • ESP32 memory constraints: storing embedded audio in flash using PROGMEM.
  • Converting WAV audio files into C headers.

Results

A working Bluetooth mouse with tilt-based movement, touchscreen clicks, scrolling mode and audio feedback at key moments.

Skills demonstrated

Embedded C++ programming on ESP32, Bluetooth Low Energy with the HID profile, inertial sensor integration and microcontroller memory management.

Technologies
