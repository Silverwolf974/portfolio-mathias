AI gesture recognition (webcam)

A deep learning system that recognises rock–paper–scissors gestures in real time from webcam images.

TypeData challenge — AI module (ESIROI)
LanguagePython
FieldComputer vision
DatasetRock Paper Scissors (TensorFlow Datasets)

Context

For the artificial intelligence module, the goal was to build a complete computer vision pipeline: the user makes a gesture in front of the camera and the model automatically predicts rock, paper or scissors.

Objectives

  • Build an end-to-end image classification system.
  • Train an effective CNN using transfer learning.
  • Analyse the model’s performance and limitations.
  • Implement an interactive real-time webcam demo.

Pipeline

The project follows a standard computer vision pipeline: webcam image capture, preprocessing (resizing and normalisation), classification by a CNN trained using transfer learning, and live display of the predicted gesture.

  • Data : TensorFlow Datasets’ Rock Paper Scissors dataset, supplemented and preprocessed (data/raw → data/processed).
  • Exploration & training : Jupyter notebooks for dataset analysis and model training.
  • Project structure : clear separation into src / models / demo / report, for reusable code.
  • Real-time demo : webcam capture with OpenCV and live predictions.

Skills demonstrated

Working across the full deep learning workflow: data preparation, CNN training and evaluation, transfer learning, and moving from a notebook to a usable real-time demonstration.

Technologies

  • TensorFlow / Keras
  • CNN / Transfer learning
  • OpenCV
