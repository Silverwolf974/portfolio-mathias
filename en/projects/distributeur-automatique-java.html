Vending machine — Java simulation

Modelling a complete vending machine in UML, then implementing it in Java: inventory, orders, payments, receipts and persistence.

TypeLab — team project
LanguageJava
DesignOOP / UML
StatusCompleted

Context

A software development lab focused on object-oriented design and UML modelling before implementation. The use case was a command-line vending machine selling sandwiches, drinks and desserts.

Architecture and modelling

Main entities: Produit, Commande, LigneCommande, Paiement, SystemePaiement, Ticket, Distributeur, StockManager. The vending machine centralises the logic, while enumerations handle order states and payment methods. UML class, sequence and activity diagrams were produced before writing the code.

Implemented features

  • Dynamic inventory display, updated in real time.
  • Multi-product orders with identical items grouped together.
  • Strict stock checks to prevent ordering more than is available.
  • Cash payments with change, or card payments through a simulated terminal.
  • Receipt generation and simulated order preparation.
  • Inventory persisted in a text file between runs.

Skills demonstrated

Turning UML analysis into a clear object-oriented architecture, managing persistent state and delivering a structured Java project as a team.
