Secure data transmission over MQTT

Encrypting environmental data end to end with AES and relaying it through an MQTT broker that never sees the plaintext.

TypeSAE — academic project (ESIROI)
TeamTwo students
LanguageJava 17
StatusCompleted and working

Context

Simulating the transmission of environmental readings (temperature and humidity) from a device to a business workstation through an MQTT broker, keeping the data confidential even from the broker itself.

Objectives

  • Understand MQTT’s publish/subscribe model.
  • Implement end-to-end AES encryption.
  • Apply robust key derivation (PBKDF2) using a shared secret.
  • Structure a modular Java application and separate configuration from code.

Architecture and operation

Three Ubuntu virtual machines on one local network: a sender (device), a receiver (business workstation) and a Mosquitto broker. An AES key is derived from a shared identifier using PBKDF2, and the MQTT topic is derived using SHA-256. The sender encrypts and publishes a JSON message; the receiver subscribes to the same topic, decrypts it and displays it. The broker handles ciphertext only. Its address is stored in an external configuration file.

Work completed

  • Setting up a local Mosquitto broker and validating the publish/subscribe flow.
  • Java classes: CryptoUtils (key derivation and encryption), ClientPublisher, ClientSubscriber.
  • AES-CBC encryption of JSON messages before publication.
  • Topic derived from the shared secret to separate exchanges.
  • External network configuration.

Results

A working end-to-end flow: data encrypted on the device, relayed without exposing plaintext to the broker, then decrypted and displayed on the business workstation. The confidentiality objective was met within the project’s scope.

Skills demonstrated

Applied cryptography (AES, PBKDF2 and SHA-256), MQTT, structured Java development and Linux administration on a local network.

Technologies

  • Java 17
  • Eclipse Paho MQTT
  • Mosquitto
  • AES-CBC
  • PBKDF2-HMAC-SHA256
  • SHA-256
  • Ubuntu Server
